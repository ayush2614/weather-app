# 🌦️ Weather Map App

A modern Weather Web App that shows **real-time weather + map + 7-day forecast** for any location including **cities, towns, and villages**.

---

## 🚀 Live Demo

👉 https://ayush2614.github.io/weather-app/

---

## ✨ Features

- 🔍 Smart Location Search (City / Town / Village)
- 📍 Auto Suggestions while typing
- 🌍 Interactive Map (using Leaflet)
- 📌 Marker for selected location
- 🌦️ Real-time Weather Data
- 📅 7-Day Weather Forecast
- 📍 "Use My Location" (GPS support)
- 💡 Works without API key (fully free)
