# 🌦 Mausam 

A real-time weather web app that shows weather and place information for any city, town, or village.

---

## 🚀 Live Demo
🔗 https://mausam-aaj-ka.netlify.app

---

## ✨ Features
- 🌤 Real-time weather data
- 📍 Smart location search (city + village)
- 🧠 Place information (Wikipedia integration)
- 🎨 Dynamic UI based on weather conditions
- 🔐 Secure API using Netlify Functions

---

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript
- OpenWeather API
- OpenStreetMap (Nominatim API)
- Netlify Functions
